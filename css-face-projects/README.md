# Ten faces in CSS

Open `index.html` or any numbered file directly in a browser. Every face is self-contained HTML and CSS. No dependencies, JavaScript, SVG, images, or code comments.

1. **Midnight Moon** — Silhouette · border-radius · layered shadows.
2. **Alley Cat** — Shared coordinates · polygon ears · symmetry.
3. **Radio Robot** — Inset geometry · repeating gradients · hover states.
4. **Count Crimson** — Angular anatomy · paint order · negative space.
5. **Peach Pierrot** — Asymmetry · translucent overlays · facial features.
6. **Orbit Astronaut** — Nested clipping · gradients · glass compositing.
7. **Woodland Elf** — Interlocking silhouettes · asymmetric planes · tiny accents.
8. **Neon Courier** — Split lighting · graphic occlusion · CSS state.
9. **Golden Harlequin** — Compound silhouettes · mask cutouts · metallic planes.
10. **Blue Hour Portrait** — Facial topology · full-plane construction · color relationships.

Each face uses a square coordinate system, layered shapes, and intentional paint order. Complexity increases through finer facial planes, asymmetry, translucent overlays, nested clipping, and smaller features.
